DEVELOPER ACCESS

API 接入

让其他本地应用通过统一接口发送消息。

查看交互式文档 ↗
01 · 认证

使用 API Key

在请求头中加入 X-API-Key。密钥位于本地 .env 文件的 MESSAGE_API_KEY，请勿放入前端代码。

02 · 发送

提交消息

向 POST /api/v1/messages 发送 JSON。一个请求可同时发往多个渠道。

cURL 示例
03 · 查询结果
检查投递状态
接口返回 202 和消息 ID。使用 GET /api/v1/messages/{id} 查询各渠道的投递状态。
⌘
接入约定
每个渠道都有固定的 ID，可在渠道管理中复制。建议业务应用为同一事件设置唯一的 idempotency_key，避免重复发送。
默认仅监听 127.0.0.1，端口可在 .env 中设置。跨机器部署时请配置 HTTPS 反向代理和访问控制。
